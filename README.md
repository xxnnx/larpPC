# LarpPC Club

Fullstack веб-приложение для управления компьютерным клубом и бронирования компьютеров.

## Структура проекта

- **`backend/`** — Бизнес-логика, работа с базой данных, авторизация, бронирования и API. Java + Spring Boot.
- **`frontend/`** — Внешний вид сайта, интерфейс и взаимодействие с пользователем. React.

## Запуск Backend

1. Перейти в папку `backend/`.
2. Запустить Spring Boot приложение через IDE или терминал:

```bash
./mvnw spring-boot:run
```

Backend будет доступен по адресу: `http://localhost:8080`

## Запуск Frontend

1. Перейти в папку `frontend/`.
2. Установить зависимости:

```bash
npm install
```

3. Запустить проект:

```bash
npm run dev
```

Frontend будет доступен по адресу, указанному в терминале.

## База данных

Для работы приложения необходим PostgreSQL. Параметры подключения настраиваются в конфигурации Backend.
